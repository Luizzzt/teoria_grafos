# Índice das evidências de execução

Cada opção do menu possui dois testes. Os arquivos TXT preservam a transcrição integral; as imagens PNG apresentam o mesmo conteúdo para inserção no relatório.

| Opção | Teste 1 | Teste 2 |
|---|---|---|
| 1 Ler arquivo | arquivo válido | arquivo inexistente |
| 2 Gravar arquivo | grafo carregado | grafo vazio |
| 3 Inserir vértice | rótulo válido | rótulo vazio |
| 4 Inserir aresta | aresta válida | peso igual a zero |
| 5 Remover vértice | remoção confirmada | remoção cancelada |
| 6 Remover aresta | remoção confirmada | aresta inexistente |
| 7 Mostrar arquivo | arquivo existente | arquivo inexistente |
| 8 Mostrar grafo | lista carregada | grafo vazio |
| 9 Conexidade | grafo conexo | grafo desconexo |
| 10 Encerrar | encerramento direto | recuperação de opção inválida e encerramento |
